# PSE-Jacobian

Reproduce and audit the counterexample to the Jacobian Conjecture in three variables, on your own machine. Three independent units of PSE agents audit the map, and a result counts only when all three agree.

- **Download:** <https://www.zeravatech.ca/downloads/examples/>, for Ubuntu and Windows, with SHA-256 checksums
- **Guide:** [app/GUIDE_EN.md](app/GUIDE_EN.md) · [app/VODIC_SR.md](app/VODIC_SR.md)
